Sandwich Sales Analysis – Power BI

## 📊 Project Overview

The **Sandwich Sales Analysis** project is an interactive **Power BI data analysis and visualization project** designed to analyze sandwich sales data and identify important sales patterns, trends, and business insights.

The project uses a sales dataset containing sandwich transaction information and transforms the raw data into meaningful visualizations through Power BI.

The goal is to demonstrate the complete data-analysis workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Modeling → Visualization → Business Insights**

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze overall sandwich sales performance.
* Identify sales trends and patterns.
* Understand which sandwich products perform better.
* Analyze sales based on available dimensions in the dataset.
* Create meaningful KPIs and interactive visualizations.
* Transform raw sales data into actionable business insights.
* Practice Power BI data preparation, modeling, and dashboard development.

## 🔄 Data Analysis Workflow

### 1. Data Collection

The project starts with the `Sandwich_Sales.csv` dataset.

### 2. Data Cleaning

The data is prepared in **Power Query** before being used for analysis.

Typical preparation activities include:

* Checking column data types
* Handling missing values
* Removing unnecessary records
* Standardizing column values
* Preparing fields for analysis

### 3. Data Transformation

The cleaned dataset is transformed into an analysis-ready structure.

### 4. Data Modeling

The prepared data is loaded into Power BI and used to create the analytical model required for the report.

### 5. DAX Calculations

DAX can be used to create business measures such as:

* Total Sales
* Total Quantity
* Average Sales
* Number of Transactions
* Product-level performance metrics

### 6. Data Visualization

Power BI visuals are used to make the sales information easier to understand and compare.
