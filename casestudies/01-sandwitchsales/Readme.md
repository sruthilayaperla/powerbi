🥪 Sandwich Sales Analysis — Power BI
📌 Project Overview

This project is a Power BI sales analysis dashboard built to understand the performance of a sandwich business.

The goal of the analysis is simple — take raw sales data and turn it into useful business insights.

The dashboard helps answer questions such as:

How much are we selling?
Which sandwiches are selling the most?
Which categories perform better?
What are the busiest sales periods?
How does sales performance change over time?
Which products contribute the most to overall revenue?
Are there any products or periods that need attention?

Instead of looking through rows of sales data, the dashboard brings the important information together in an interactive and easy-to-understand format.

🎯 Business Objective

The main objective of this project is to analyze sandwich sales and identify patterns that can help improve business performance.

The analysis focuses on:

Overall sales performance
Product-level performance
Sales trends over time
Quantity sold
Customer ordering patterns
Best-selling and underperforming products
Identifying opportunities for improving sales

The idea is to move from raw data → analysis → insights → business decisions.

📊 Dashboard

The Power BI dashboard provides an interactive view of the sandwich sales data.

Users can explore the data using filters and visualizations to understand sales performance from different perspectives.

Key areas covered

Sales Overview

Provides a high-level view of the business using important KPIs such as:

Total Sales
Total Orders
Total Quantity Sold
Average Order Value

Product Analysis

Shows which sandwich products are contributing the most to sales and which products have lower demand.

Time Analysis

Helps identify sales patterns across different dates, months, days, or other available time periods.

Category Analysis

Allows sales to be compared across the available sandwich/product categories.

Interactive Analysis

Slicers and filters allow users to drill into specific products, periods, and other dimensions available in the dataset.

🔄 Data Analysis Process

The project follows a simple end-to-end BI workflow:

Raw Sales Data
      ↓
Data Cleaning
      ↓
Data Transformation
      ↓
Data Modeling
      ↓
DAX Calculations
      ↓
Power BI Visualizations
      ↓
Business Insights

1. Data Collection

The sales dataset contains transaction-level information related to sandwich orders.

2. Data Cleaning

The data was reviewed and prepared for analysis using Power Query.

This step ensures that the dataset is consistent and suitable for reporting.

3. Data Modeling

The cleaned data was loaded into Power BI and structured for analysis.

Relationships and appropriate fields were used to allow the dashboard visuals to interact correctly.

4. KPI Creation

DAX measures were created to calculate the key business metrics required for the dashboard.

5. Dashboard Development

The final dashboard combines KPI cards, charts, tables, and interactive filters to present the analysis in a simple business-friendly format.
